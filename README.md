# Mariana Martins Portfolio

A professional portfolio website showcasing Cloud Engineering and DevOps expertise.

**Live Site:** https://marianamartins-tech.github.io/portfolio/

## Features

- Clean, modern design with smooth animations
- Responsive layout for all devices
- GSAP scroll animations
- Interactive skill cloud
- Contact form
- Featured projects including Kirchhoff Studios

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- GSAP (animations)
- shadcn/ui components

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

This site is automatically deployed to GitHub Pages via GitHub Actions when you push to the main branch.
